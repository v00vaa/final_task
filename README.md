# Планировщик задач
## Описание проекта
Проект разработан в рамках финального задания по курсу «Go-разработчик с нуля» от Яндекс Практикума.

Проект представляет собой веб-приложение для управления списком задач (TODO-лист) одного пользователя.

Приложение позволяет:

- добавлять задачи с указанием даты, названия, комментария и правила повторения;
- просматривать список задач;
- искать задачи по названию и комментарию;
- искать задачи по дате;
- редактировать задачи;
- отмечать задачи как выполненные;
- удалять задачи;
- автоматически вычислять следующую дату для повторяющихся задач;
- использовать правила повторения для дней, недель и месяцев;
- выполнять аутентификацию пользователя;
- хранить данные в базе данных SQLite.

Веб-интерфейс приложения размещён в каталоге `web/`, серверная часть реализована на языке Go.

## Инструкция по запуску кода

### Требования

Для локального запуска необходимо установить:

- Go;
- SQLite отдельно устанавливать не требуется, так как приложение работает с базой данных SQLite через Go-библиотеку.

### Переменные окружения

Приложение поддерживает следующие переменные окружения:

| Переменная      | Назначение                      | Значение по умолчанию |
|-----------------|---------------------------------|-----------------------|
| `TODO_PORT`     | Порт веб-сервера                | `7540`                |
| `TODO_DBFILE`   | Путь к файлу базы данных SQLite | `scheduler.db`        |
| `TODO_PASSWORD` | Пароль для аутентификации       | не задан              |

Для локального запуска можно создать файл `.env` в корне проекта:

```env
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=1234
```

### Запуск

Из корневого каталога проекта выполнить:
`go run .`

После запуска приложение будет доступно по адресу:
`http://localhost:7540`

Для открытия веб-интерфейса необходимо перейти в браузере по адресу:
`http://localhost:7540`

При использовании другого значения TODO_PORT адрес будет иметь соответствующий порт. Например:
`TODO_PORT=8080`

Тогда приложение будет доступно по адресу:
`http://localhost:8080`

Также проект можно предварительно собрать:
`go build -o scheduler .`

И затем запустить полученный исполняемый файл:
`./scheduler`

В Windows:
`.\scheduler.exe`

## Инструкция по сборке и запуску проекта через докер
Для проекта реализована возможность сборки Docker-образа.

## Сборка образа

Из корневого каталога проекта выполнить:  
`docker build -t todo-server .`

После успешной сборки будет создан образ:
`todo-server`

## Запуск контейнера

Для хранения базы данных на хост-компьютере рекомендуется создать каталог:  
`mkdir docker-data`

Затем запустить контейнер:
```
docker run `
    --name todo `
    -p 7540:7540 `
    -v "${PWD}\docker-data:/data" `
    -e TODO_PORT=7540 `
    -e TODO_DBFILE=/data/scheduler.db `
    -e TODO_PASSWORD=1234 `
    todo-server
```
После запуска приложение будет доступно в браузере по адресу:

`http://localhost:7540`

Файл базы данных будет храниться в каталоге:

docker-data/scheduler.db
